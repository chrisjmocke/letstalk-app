# Let's Talk - Android app downloads

**Let's Talk** translates and speaks between all 11 official South African languages and 9 more (Amharic, Arabic, Bengali, French, Hindi, Mandarin, Portuguese, Somali and Urdu). Hold to talk, type, scan text or translate a voice note, and practise phrases on the Learn page.

Website: **https://www.talksa.co.za**

## Download

**[Download the latest APK](https://github.com/chrisjmocke/letstalk-app/releases/latest/download/lets-talk.apk)** (Android only)

Release notes for every version are on the [Releases page](https://github.com/chrisjmocke/letstalk-app/releases).

## How to install

1. Download the APK on your Android phone.
2. Open the downloaded file from your notifications or your Downloads folder.
3. If your phone asks, allow installs from your browser or file manager ("Install unknown apps").
4. Tap **Install**, then open Let's Talk and allow the microphone when asked.

To update, install the newest APK over the old one. Your credits and history stay.

Only install Let's Talk from this page or from www.talksa.co.za. Every release is signed by us.
